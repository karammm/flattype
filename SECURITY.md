# Security policy

Please report vulnerabilities privately through
[GitHub security advisories](https://github.com/karammm/flattype/security/advisories/new), not in a public issue.
Include the input that triggers the problem if you can. You'll get a reply within a few days.

What FlatType guarantees, and how each guarantee is tested: https://karammm.github.io/flattype/docs/guide/security

Only the latest `1.x` release receives fixes.
